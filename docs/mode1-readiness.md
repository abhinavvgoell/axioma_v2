## Gate 1 exit criteria

Do not start Mode 2 until all of these are supported by artifacts and recorded commands:

1. **Met locally:** Python and Java submissions completed in Docker for function and stdin/stdout paths.
2. **Met locally:** all 6 Docker-backed abuse checks passed on Docker Desktop's Linux-container runtime; none were skipped.
3. **Not met:** 50 solutions have human-reviewed labels and source provenance, but one implementation does not terminate on valid inputs and has no finite complexity class. The 49 scorable cases are below the evaluator minimum; held-out accuracy is low. Improve the analyzer on calibration cases and use a new untouched holdout for the next evaluation.
4. **Met locally, smoke set only:** one correct control and three source-reviewed mutants were labeled before Axioma checks; the report records 3/3 detected mutants, 0/1 flagged correct controls, denominators, and wide Wilson intervals. Broader problem and fault coverage remains necessary for general claims.
5. **Met locally, narrow scope:** two Python candidates were preselected, passed all configured equivalence checks, and have paired counts at four increasing sizes with preselection manifests and raw source reports. The measurements are line/opcode work counts, not wall-clock speedup.
6. **Met locally, with a limitation:** a clean run of 20 sequential Python jobs in a fresh PostgreSQL database completed with valid timing in all 20 cases. The report is Python-only, small, and host-specific; it is descriptive and does not establish a public service SLO.
7. **Met:** all 152 API, worker, and evaluator tests pass, including Docker sandbox checks and PostgreSQL queue behavior; Ruff, frontend lint and production build pass; PostgreSQL migrations are at head; hosted CI run #27 passes for commit `3d8f7f6`.
8. **Met locally:** the user approved the analyzer UI on 2026-10-22. Their separate final frontend designs may still inform future UI work.

The current repository has working implementation paths and reproducible evaluator tools, but Gate 1 is not complete. The first human-reviewed complexity evaluation found 49 scorable samples, with 33.3% exact accuracy on the held-out partition; several basic algorithms still abstain or receive the wrong class. The current held-out examples have now been inspected, so future analysis changes need a newly selected untouched holdout. Detection and optimization evidence remain narrow local smoke evaluations and must not be generalized. The controlled 20-job latency sample is too small and narrow to establish a public service SLO. The evaluator's 50-solution indicator is only a count check; it cannot verify label quality or independence.

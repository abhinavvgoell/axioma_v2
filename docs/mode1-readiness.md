## Gate 1 exit criteria

Do not start Mode 2 until all of these are supported by artifacts and recorded commands:

1. **Met locally:** Python and Java submissions completed in Docker for function and stdin/stdout paths.
2. **Met locally:** all 6 Docker-backed abuse checks passed on Docker Desktop's Linux-container runtime; none were skipped.
3. At least 50 distinct solutions have independently reviewed complexity labels, with source/problem provenance and a held-out evaluation partition where calibration is reported.
4. **Met locally, smoke set only:** one correct control and three source-reviewed mutants were labeled before Axioma checks; the report records 3/3 detected mutants, 0/1 flagged correct controls, denominators, and wide Wilson intervals. Broader problem and fault coverage remains necessary for general claims.
5. **Met locally, narrow scope:** two Python candidates were preselected, passed all configured equivalence checks, and have paired counts at four increasing sizes with preselection manifests and raw source reports. The measurements are line/opcode work counts, not wall-clock speedup.
6. **Met locally, with a limitation:** a clean run of 20 sequential Python jobs in a fresh PostgreSQL database completed with valid timing in all 20 cases. The report is Python-only, small, and host-specific; it is descriptive and does not establish a public service SLO.
7. **Met:** all 152 API, worker, and evaluator tests pass, including Docker sandbox checks and PostgreSQL queue behavior; Ruff, frontend lint and production build pass; PostgreSQL migrations are at head; hosted CI run #25 passes for commit `ddb35db`.
8. The user supplies the final frontend visual design and signs off on the local demo flow.

The current repository has working implementation paths and reproducible evaluator tools, but Gate 1 is not complete. The main evidence gap is the 50-solution human-reviewed complexity set with a held-out partition; a local review packet is prepared, but labels remain blank until a human reviewer inspects each solution. Detection and optimization evidence now exist only as narrow local smoke evaluations and must not be generalized. The controlled 20-job latency sample is available, but it is too small and narrow to establish a public service SLO. The 50-solution indicator in the evaluator is only a count check; it cannot verify that labels are independent or correct. Final UI sign-off remains pending.

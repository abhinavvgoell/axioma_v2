# Complexity label normalization

The evaluator has seven ordered buckets. Original human labels and rationales remain in each gold row as `reviewed_complexity` and `rationale`. Use total input size N for combined dimensions: additive scans map to O(n); O(log(m+n)) to O(log n); O(m*n) DP to O(n^2); O(m*k) substring-concatenation work to O(n^2); O(9^E), O(4^n*n), and exponential-output Word Break II map to one exponential-family bucket O(2^n). This is a categorical family bucket, not a mathematical upper bound by 2^n. O(V+E) maps to O(n); O(C+U^2) maps to O(n) because U<=26; near-linear O(V+q*alpha(V)) DSU maps conservatively to O(n log n). Rotated-array minimum with duplicates is scored by worst-case O(n). Static estimates are parsed by leading supported class; unknown/unrecognized estimates become `unknown`, while full reports are preserved.

The graph path-existence sample is excluded from class accuracy: its code never inserts visited nodes and can recurse forever on valid inputs, so it has no finite complexity class. Its source and report remain preserved. The 3Sum prompt was abbreviated and omitted pointer advances; scoring uses the verified packet source with pointer advancement after a match.

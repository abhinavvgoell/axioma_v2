## Conventions proposed for review

- Measure worst-case time unless a case explicitly gives a different convention. Use the packet's stated input-size variable and assumptions.
- Use the standard word/cell model for primary labels: scalar operations and stored scalar values count as O(1); exclude input storage and returned output storage; include auxiliary data structures and recursion stack.
- Case 17's O(n) time and space labels use that conventional model. Python arbitrary-precision integer bit costs would instead make additions O(n²) total bit work and cached value storage O(n²) bits. This is called out as a model caveat, not silently mixed into the primary label.
- If a label remains genuinely ambiguous after review, mark it before analysis and exclude it from the relevant scorable denominator; retain the case and report the exclusion. Unknown analyzer outputs count as abstentions, not correct answers.

# Axiōma UI prototype

This is a standalone visual prototype. It is not mounted in FastAPI and does not call the Axioma API. The workspace interactions use illustrative sample data only.

From the repository root, serve this folder locally:

```powershell
py -m http.server 4173 --directory frontend-prototype
```

Then open <http://127.0.0.1:4173/>. No frontend build step or external font download is required.
